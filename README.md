# Streamer.bot Tools by PhaiTing
This is a collection of tools for use in or with Streamer.bot.

Streamer.bot has already taken the step to make a powerful tool available for free to the streaming community to enhance
their streams by adding functionality or by enabling automation.

My goal is to help empower streamers who are not comfortable writing code in C# or who might even have very little 
programming experience. My tools will be written in as much native Streamer.bot actions as possible or as is practical.
When I do write code in C#, I will share that source code here but it can also bew viewed withing Streamer.bot itself.

I hope you find my tools helpful and I do encourage you to customize them for your own needs.

Enjoy, citizen.

StreamerBot can be found at:
[streamer.bot](https://streamer.bot/)

## How to import into StreamerBot
I will be saving files to import into StreamerBot with a ".sb" extension. 

You can find my [Streamer.bot Importing Tutorial](https://www.youtube.com/watch?v=gHqw3gwpbco) on YouTube.
